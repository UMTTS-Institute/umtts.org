## CANONICAL FOLDER STRUCTURE

Every terrain contact package uses this exact layout.
The terrain slug replaces `[SLUG]`. The ISO date replaces `[DATE]`.

```
UMTTS_TC_[SLUG]_[DATE]/
│
├── README.txt                        # Human-readable overview. What this package is,
│                                     # what terrain it contacts, what was sealed when,
│                                     # and how to navigate the package.
│
├── MANIFEST.sha256                   # SHA256 hash of every file in the package.
│                                     # Generated by package_terrain_contact.py.
│                                     # Format: <hash>  <relative-path>
│
├── 01_SEALED_PREDICTION/
│   ├── prediction-record.md          # Extracted Layer 1 fields: prediction text,
│   │                                 # falsifiers, eligibility rules, prohibited inputs,
│   │                                 # DOI, preparation date, terrain opening date.
│   ├── source-csv-rows.txt           # Verbatim CSV row(s) with SHA256 hashes.
│   ├── [MH_PREDICTION_NN_...].md     # Full prediction document (copy of canonical file).
│   └── [MH_PRED_V1_NN_...].csv       # Full prediction CSV with per-row hashes.
│
├── 02_TERRAIN_MANIFEST/
│   ├── manifest.csv                  # Every record examined. Columns:
│   │                                 #   ID, release_timestamp, source_url,
│   │                                 #   file_hash_sha256, included (yes/no),
│   │                                 #   exclusion_reason (if excluded)
│   ├── manifest-summary.md           # Totals: eligible, excluded, exclusion breakdown.
│   └── download-log.txt              # Retrieval timestamps and URLs per file.
│
├── 03_TRANSFORMATION_LEDGER/
│   ├── pathway-1-ledger.md           # Full chain: raw file → scored quantity.
│   ├── pathway-2-ledger.md           # One file per prediction pathway.
│   ├── pathway-N-ledger.md           # For each step: input hash, operation,
│   │                                 # code reference (file:line), parameters,
│   │                                 # output hash, validation check.
│   └── intermediate/
│       └── [hashed intermediate artifacts]
│
├── 04_EXECUTABLE_SCORER/
│   ├── [analysis_script_1].py        # All Python analysis scripts.
│   ├── [analysis_script_2].py
│   ├── requirements.txt              # Dependencies with exact pinned versions.
│   ├── environment.txt               # Python version, OS, hardware notes.
│   ├── run-command.txt               # Exact invocation string(s).
│   ├── random-seeds.txt              # All random seeds used (for reproducibility).
│   └── output/
│       ├── [output_files]            # All generated output files.
│       └── output-hashes.txt         # SHA256 of each output file.
│
├── 05_AGENT_AUDIT_PACKET/
│   ├── audit-instructions.md         # Governing instructions sent to the agent.
│   ├── documents-supplied.txt        # List of files/documents supplied.
│   ├── session-transcript.md         # Exact questions asked, findings returned,
│   │                                 # corrections made, citations used.
│   ├── agent-model-version.txt       # Model identifier and version used.
│   └── final-evidence-table.md       # Evidence table used for falsifier determination.
│
├── 06_FALSIFIER_ADJUDICATION/
│   ├── adjudication-sheet.html       # Standalone HTML - one table per pathway.
│   │                                 # Human-readable. No domain expertise required.
│   └── adjudication-sheet.csv        # Machine-readable equivalent.
│
├── 07_FULL_RECORD/
│   └── [SLUG]-FULL-RECORD.html       # *** THE PRIMARY ARTIFACT ***
│                                     # Self-contained HTML. No external dependencies.
│                                     # Contains verbatim: full prediction text,
│                                     # full derivational chain (all steps), full results,
│                                     # falsifier adjudication, source equations,
│                                     # replication instructions.
│                                     # Downloading this ONE file gives the complete record.
│                                     # Opens offline. No links required.
│
└── 08_REPLICATION_CHALLENGE/
    ├── challenge.html                # Published challenge page.
    ├── expected-output.txt           # Key expected quantities.
    └── expected-output-hash.txt      # SHA256 of expected-output.txt.
```

## INVARIANT RULES

1. **No file is omitted because it appears unfavorable.**
2. **The MANIFEST is generated LAST** - after all other files are in place.
3. **The FULL-RECORD HTML is self-contained** - all CSS inline, all math rendered
   as Unicode/UTF8 (never LaTeX), no external requests required for basic reading.
4. **Random seeds are always documented** in `04_EXECUTABLE_SCORER/random-seeds.txt`.
5. **The zip archive SHA256 is printed to console** by `package_terrain_contact.py`
   and must be published alongside the download link.
6. **The prediction document is copied verbatim** into `01_SEALED_PREDICTION/` -
   it is never summarized or paraphrased in the package.
7. **Intermediate artifacts are kept** - even if they appear to show only null results.

## THE FULL-RECORD HTML - REQUIRED SECTIONS

The self-contained `07_FULL_RECORD/[SLUG]-FULL-RECORD.html` must contain,
in order, without external links required:

1. **Cover block** - terrain, sealed date, terrain date, DOI, verdicts summary
2. **Governing source chain** - the MFE and source equations (verbatim, Unicode)
3. **Input separation statement** - verbatim from CSV
4. **Eligibility and exclusion rules** - verbatim from prediction document
5. **Per-pathway sections** (one per prediction):
   a. Full prediction statement (verbatim)
   b. Full derivational chain (all numbered steps, verbatim from prediction doc)
   c. Falsifier (verbatim)
   d. Observed terrain result (raw quantities)
   e. Controls
   f. Verdict
6. **Unified prediction matrix** - the table from Section IX
7. **Falsifier adjudication** - compact verdict table per pathway
8. **Signal quality notes** - distinguishes signal attenuation from verdict
9. **Measurement layer notes** - topology sentinels, B-factor notes, etc.
10. **Replication instructions** - how to run the scorer
11. **Source register** - canonical source files cited
